# Installing RetroPie
## Install Raspi-Imager

> [!WARNING] ChromeOS(chromebook) NOT COMPATIBLE!

[Download app here (select correct operating system; example: macOS, Windows, linux, etc.)](https://www.raspberrypi.com/software/)

## Image Micro-SD card
1. Lunch the installed app and if needed follow extra instructions given in app.
2. Select the device model in app
3. Choose OS(Operating System)
> [!NOTE] How To Select RetroPie:
> 1. Scroll down to "Emulation and Game OS"
> 2. Select "RetroPie"
> 3. Choose your device model if more than one
4. Select the target storage drive you are willing to sacrifice(**ALL DATA WILL BE ERASED!**) in the menu, **DO NOT SELECT THE SYSTEM DRIVE!!!**
5. If prompted don't enable SSH, we will later...
6. Press start
7. Wait for it to finish; **DON NOT UNPLUG TARGET DRIVE**.
8. Press Complete/Finish
9. Unplug Drive and plug it into the Raspberry PI
10. Plug Micro-SD card into the Raspberry PI with all other Required cables/devices.
> [!IMPORTANT] Required cables/devices:
> - Power
> - Keyboard
> - HDMI
> - At least one USB Controller if hardwired buttons/joysticks not connected
> - The Micro-SD Card
> - No Mouse (Not Required)
11. Restart Raspi(Raspberry PI)
> [!TIP] How To Power Cycle Raspi:
> Unplug Power cable, wait 10 seconds, Plug Power cable back in
12. Wait till it does it stuff and shows a configuration message then proceed to the next part of this guide.
